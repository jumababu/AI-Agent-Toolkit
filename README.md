# AI Assistant & Automation Toolkit
This repository contains Python-based tools and agentic logic used to power autonomous assistants. 

### Current Capabilities:
- **Weather Engine**: Fetches real-time meteorological data via OpenWeatherMap API.
- **Logistics Engine**: Calculates travel distance and time using Google Maps Distance Matrix.
- **N8N Integration**: Workflows designed for WhatsApp/Telegram triggers to handle multi-step user queries.

### Tech Stack:
Python, N8N, MongoDB, Ubuntu (Self-hosted)
